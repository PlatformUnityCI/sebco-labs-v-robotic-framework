# GUÍA DE VERIFICACIÓN Y AUDITORÍA DEL ENTORNO EN macOS

**Proyecto:** `sebco-labs-v-robotic-framework`

**Entorno:**  
<span style="color:#B0005A;"><strong>macOS (Zsh)</strong></span>

---

# 1. Objetivo

Esta guía define una serie de verificaciones básicas para validar el estado del entorno local de desarrollo luego de instalar dependencias, ejecutar herramientas externas o revisar incidentes reportados en repositorios públicos.

El objetivo es:

- detectar configuraciones inesperadas,
- revisar posibles mecanismos de persistencia,
- validar procesos activos,
- confirmar que el entorno de trabajo permanezca bajo control.

---

# 2. Checklist de verificación

## [ ] 1. Revisar historial de comandos

Permite identificar instalaciones o ejecuciones inesperadas dentro de la terminal.

```bash
history | grep -E "pip|npm|yarn|pnpm|bun"
```

### Verificación

- Revisar comandos recientes relacionados con gestores de paquetes.
- Confirmar que las ejecuciones correspondan a acciones realizadas conscientemente.
- Validar que no existan instalaciones automáticas o scripts desconocidos.

---

## [ ] 2. Auditar configuraciones de IDEs

Algunas dependencias maliciosas modifican configuraciones locales o agregan tareas automatizadas dentro del editor.

### Revisar extensiones instaladas de VS Code

```bash
cat ~/.vscode/extensions/*/package.json 2>/dev/null | grep -i "postinstall"
```

### Verificación manual del repositorio

Revisar la existencia de:

- `.vscode/`
- `.claude/`

En caso de existir:

- inspeccionar `tasks.json`,
- inspeccionar `settings.json`,
- validar que no ejecuten binarios desconocidos,
- validar que no existan descargas o redirecciones externas no esperadas.

Ejemplo:

```bash
cat .vscode/tasks.json
```

---

## [ ] 3. Revisar procesos activos

Permite identificar procesos persistentes relacionados con Python o Node.js.

```bash
ps aux | grep -E "python|node"
```

### Verificación

Validar que los procesos:

- correspondan a herramientas conocidas,
- utilicen entornos virtuales esperados,
- pertenezcan al sistema operativo o al entorno de desarrollo actual.

En caso de detectar procesos desconocidos:

- revisar la ruta de ejecución,
- identificar el PID asociado,
- finalizar el proceso o reiniciar el sistema si corresponde.

---

## [ ] 4. Verificar archivo hosts

Algunas modificaciones maliciosas alteran la resolución local de dominios mediante cambios en `/etc/hosts`.

```bash
cat /etc/hosts
```

### Estructura esperada en macOS

```text
##
# Host Database
#
# localhost is used to configure the loopback interface
# when the system is booting.
##
127.0.0.1       localhost
255.255.255.255 broadcasthost
::1             localhost
```

### Verificación

Validar que:

- no existan dominios desconocidos,
- no haya redirecciones inesperadas,
- las entradas correspondan únicamente a configuraciones locales conocidas.

# 4. Recomendaciones generales

- Utilizar entornos virtuales aislados (`.venv`).
- Evitar ejecutar scripts externos sin revisión previa.
- Mantener dependencias bloqueadas mediante hashes cuando sea posible.
- Revisar periódicamente configuraciones locales del editor.
- Mantener actualizado el sistema operativo y las herramientas de desarrollo.

La guía está orientada a revisiones rápidas de integridad y no reemplaza herramientas especializadas de análisis o monitoreo de seguridad.
